## v3.0 AI Automation Funnel (Shipped: 2026-04-24)

**Phases completed:** 18 phases, 63 plans, 100 tasks

**Key accomplishments:**

- One-liner:
- Prisma 7 ORM configured with SQLite, database schema with 5 models, and MYR currency utilities with sen integer storage
- Email/password registration with bcrypt hashing, session cookies, and protected routes via middleware
- Desktop sidebar with Dashboard/Properties/Tenants/Settings links, mobile hamburger menu with slide-out navigation, and dashboard home page with placeholder stat cards
- Property CRUD with responsive cards/table layout and progressive forms
- Lease Management with 4-step wizard, deposit separately stored, and auto-expiration tracking
- Payment recording system with lease-linking, auto-status calculation, and MYR currency handling
- Phase goal:
- Financial Dashboard with income/expense bar charts, summary cards with totals, and outstanding payments with color-coded alerts
- One-liner:
- In-app notification system with bell UI, panel, and automated payment/lease reminders
- Email notification system with SMTP transport for payment due and lease expiry alerts
- Multi-step CSV import wizard with preview, field mapping, validation, and execution for properties, tenants, and leases using papaparse
- LHDN progressive tax brackets with Zakat perniagaan (2.5%, RM 20k nisab) calculation utilities
- Profit & Loss statement with Zakat perniagaan (2.5%, RM 20k nisab) calculation
- LHDN progressive tax brackets with Zakat perniagaan offset (allowed under Malaysian law)
- Interactive Zakat and Tax calculator accessible from Settings page
- Excel exports updated to include Zakat and Tax columns in financial reports
- Database model and service for enabling/disabling marketing channels (Instagram, Facebook, WhatsApp, Website)
- Instagram Graph API and Facebook integration for posting vacant properties to social media
- Twilio WhatsApp API integration for broadcasting property listings to tenants
- JSON and RSS feed endpoints for external websites to sync vacant property listings
- Automatic and manual marketing triggers for vacant properties
- WhatsApp broadcast API endpoint and standalone dialog component for tenant communication
- Marketing channel configuration and multi-platform posting for vacant properties via Instagram, Facebook, WhatsApp, and website feeds
- Plan:
- Dashboard components for YTD summary, property performance, occupancy trends, and cash flow forecast using Recharts
- One-liner:
- Excel export support for property performance, tenant analytics, and business summary reports using business-summary-service
- Add income source field to database schema and update Prisma client
- Income source dropdown with smart categorization based on expense category in payment form
- Income source filter and colored badges added to payments list, new expense allocation report component created
- Expense allocation section added to Business Summary report with PieChart visualization showing breakdown by income source
- Profit-by-source report service with date filtering for Sublet, Autoren Sell, Autoren Rent
- Profit-by-source report component with table and cards view, date filtering, and loss highlighting
- Added bar, pie, and line charts to profit-by-source report for visual profit analysis
- Sidebar navigation with profit report dropdown menu
