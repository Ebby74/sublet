### Phase 5: Malaysian Tax & Zakat

**Goal:** Users can calculate Zakat and income tax with LHDN-compliant brackets

**Depends on:** Phase 3 (Financial Core)

**Requirements:** TX-01, TX-02, TX-03, TX-04

**Success Criteria** (what must be TRUE):
1. User can view P&L statement showing total income, total expenses, net profit
2. System calculates Zakat (2.5% of net profit) when profit exceeds RM 20,000 nisab
3. User can view tax calculation based on LHDN brackets
4. Zakat can be offset against tax liability (permitted under Malaysian law)
5. User can access Zakat & Tax calculator from Settings page

**Plans:** 5 plans
- [ ] 05-01-PLAN.md — Tax & Zakat calculation utilities
- [ ] 05-02-PLAN.md — P&L statement with Zakat section
- [ ] 05-03-PLAN.md — Tax calculation and Zakat offset
- [ ] 05-04-PLAN.md — Settings page Zakat & Tax calculator
- [ ] 05-05-PLAN.md — Excel export with Zakat/Tax columns

### Phase 6: Auto Marketing & Posting

**Goal:** Automatically market vacant properties to multiple channels

**Depends on:** Phase 2 (Property & Tenant Management)

**Requirements:** MKT-01, MKT-02, MKT-03, MKT-04, MKT-05, MKT-06

**Success Criteria** (what must be TRUE):
1. User can configure which marketing channels are enabled/disabled
2. User can post vacant properties to Instagram and Facebook
3. User can send WhatsApp broadcasts to interested tenants
4. External websites can sync vacant property listings via JSON/RSS feed
5. System auto-posts when property becomes vacant
6. User can manually trigger marketing for any property

**Plans:** 6 plans
- [ ] 06-01-PLAN.md — Marketing channel configuration (Settings UI)
- [ ] 06-02-PLAN.md — Social media posting (Instagram/Facebook)
- [ ] 06-03-PLAN.md — WhatsApp broadcast to tenants
- [ ] 06-04-PLAN.md — Website integration (JSON/RSS feed)
- [ ] 06-05-PLAN.md — Marketing triggers (auto + manual)
- [x] 06-06-PLAN.md — Gap closure: WhatsApp API endpoint and UI dialog (COMPLETED)
