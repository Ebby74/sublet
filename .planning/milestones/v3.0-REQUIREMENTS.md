## Business Context

**AMR Home Solutions** runs a co-living room rental business:
- Sublet = sub-let = letting whole property, then sub-letting by individual rooms
- Target: Young adults fresh in workforce who can't afford whole property
- Dual purpose:
  1. Profit from room rentals
  2. "Amal jariah" — help less fortunate build careers
- Use **100% AI automation** from listing creation to offer acceptance
- AI bot named **AIrene** handles ALL engagements from start to finish
- **Manual input needed:**
  - Only photos/videos + property info (from user/Annah)
  - When prospect books a viewing
- **JV Stakeholders** get limited dashboard access (view properties, income/expenses, profit sharing). AMR Homes may also own properties and become a JV Stakeholder itself, subletting their own properties.
- Their contribution is their properties; in return they get profit sharing portion
- **Property Owners (Future):** External owners may contact to list properties for AMR to sublet (next project)
- All activity/transaction done online fully automated

**Inspiration:** AMR Home Solutions (clean, minimalist, orange + grey)

## Requirements

### AI-001: AI Room Listing Creation
**Description:** Create room listings automatically from photos, videos, and property info input by user.

**Core Features:**
- Property/media upload interface (photos + videos)
- Room extraction from property (identify individual rooms)
- Room listing model (beds, baths, amenities, photos, videos)
- Media gallery with thumbnails
- Status workflow: draft → active → rented

**Technical Notes:**
- Extend Property model with room listings
- Add Room model with media fields
- Use file upload to local storage or cloud storage

---

### AI-002: AI-Generated Descriptions/Captions
**Description:** Generate compelling rental descriptions and social media captions using AI.

**Core Features:**
- AI description generation from room details + amenities
- Caption generation for each marketing channel
- Description templates with customization
- Multi-language support (English, Malay)
- Re-generation capability

**Technical Notes:**
- Integration with AI API (OpenAI, Anthropic, or local model)
- Template-based generation with room data
- Channel-specific caption variations

---

### AI-003: Auto-Post to ALL Channels
**Description:** Automatically post listings to all configured marketing channels.

**Core Features:**
- Channel-specific post formatting (Instagram, Facebook, WhatsApp, Website)
- Auto-post on listing creation/activation
- Manual re-post trigger
- Post history and status tracking
- Multi-channel toggle per listing

**Technical Notes:**
- Uses existing marketing channel infrastructure from v1.1
- Channel-specific content transformation
- Scheduling capability

---

### AI-004: Prospect Inquiry Management
**Description:** Track and manage prospect inquiries through the rental funnel.

**Core Features:**
- Prospect database (name, email, phone, source)
- Inquiry from listing (which listing, room)
- Status workflow: new → contacted → interested → viewing scheduled → viewed → offer_made → offer_accepted → tenant
- Inquiry source tracking (channel)
- Notes and communication log

**Technical Notes:**
- New Prospect model
- Inquiry status enum
- Link prospects to listings

---

### AI-005: Offer System (AI Accept/Reject)
**Description:** AI-powered offer acceptance/rejection based on criteria.

**Core Features:**
- Offer submission form for prospects
- AI evaluation criteria (credit check simulation, income requirements)
- Auto-accept/reject based on rules
- Manual override capability
- Offer letter generation with terms

**Technical Notes:**
- Offer model with status
- Simple rule-based AI evaluation
- Lease creation from accepted offer

---

### AI-006: Booking Viewing
**Description:** Allow prospects to book property viewings.

**Core Features:**
- Viewing slot management (admin sets available times)
- Prospect booking interface
- Confirmation SMS/WhatsApp
- Reminder notifications
- Viewing result recording (interested/not interested)

**Technical Notes:**
- Viewing model with booking status
- Link to prospect and listing
- Uses existing WhatsApp service from v1.1

---

### AI-007: JV Stakeholder Portal
**Description:** Limited dashboard access for JV partners.

**Core Features:**
- JV user role (view-only)
- Property performance for assigned properties
- Income/expense summary
- Profit sharing calculation display
- No sensitive data (no tenant details, edit access)

**Technical Notes:**
- Extend User model with JV role
- Scope data by assigned properties
- Read-only dashboard views

---

### AI-008: Profit Sharing Calculation
**Description:** Calculate and display profit sharing for JV stakeholders.

**Core Features:**
- Revenue attribution by property
- Expense allocation by property
- Net profit calculation: revenue - expenses
- Profit split percentage configuration
- Monthly/quarterly profit sharing reports
- Payment scheduling to stakeholders

**Technical Notes:**
- Property-JV stakeholder relationship
- Profit calculation service
- Profit sharing report generation
