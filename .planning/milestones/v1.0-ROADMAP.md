## Out of Scope (v2+)

| Feature | Reason |
|---------|--------|
| Multi-user access | Complexity for MVP; single-owner first |
| Microsoft Graph API Excel sync | CSV export sufficient for v1 |
| Payment gateway integration | Requires bank partnership |
| LHDN e-invoice API | Manual export meets v1 needs |
| WhatsApp notifications | Email/in-app sufficient for MVP |
