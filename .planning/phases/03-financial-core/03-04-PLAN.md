**Create `src/services/export-service.ts`:**

**ExportService class with methods:**

1. **`exportTransactions(filters)`**: All payments
   - Columns: Date, Reference, Type, Amount, Tenant, Property, Description, Status

2. **`exportByTenant(tenantId)`**: Per-tenant payment history
   - Columns: Tenant Name, IC Number, Property, Date, Type, Amount, Description

3. **`exportByProperty(propertyId)`**: Per-property summary
   - Columns: Property, Tenant, Monthly Rent, Total Paid, Total Outstanding

4. **`exportBills(userId)`**: Bills tracking
   - Columns: Property, Bill Type, Amount, Due Date, Paid Date, Status
   - Bill types: TNB, SYABAS, Internet, IWK

5. **`exportLHDN(userId)`**: LHDN Perbent 2024 format
   - Property address
   - Tenant name + IC number
   - Rental income (monthly)
   - Deposit held
   - Period covered
   - Uses standard LHDN column layout

6. **`exportProfitLoss(userId, year)`**: P&L statement
   - Income section: Rent received, Other income
   - Expenses section: Maintenance, Utilities, Insurance, Legal, Agent fees
   - Net profit calculation

7. **`exportBalanceSheet(userId)`**: Balance Sheet
   - Assets: Receivables, Deposits (in trust)
   - Liabilities: Deposits (in trust)
   - Net worth

8. **`exportCashBook(userId, period)`**: Cash Book
   - Receipts: Date, Reference, From, Amount
   - Payments: Date, Reference, To, Amount
   - Running balance

**Excel formatting:**
- MYR currency format: "RM 1,500.00" (D-27)
- Date format: DD/MM/YYYY (D-28)
- Header row with bold + background
- Auto column width

**Create `src/app/api/v1/export/route.ts`:**

1. Handler: GET with query params
   - `?format=transactions|by-tenant|by-property|bills|lhdn|p&l|balance-sheet|cash-book`
   - `?period=this-month|last-month|this-year|custom`
   - `?startdate=YYYY-MM-DD&enddate=YYYY-MM-DD` (for custom)
   - `?tenantId=xxx` (for by-tenant)
   - `?propertyId=xxx` (for by-property)

2. Validates format is supported

3. Calls appropriate export-service method

4. Returns file:
   - Format: xlsx (default) or csv
   - Filename: `{format}-{date}.xlsx`
   - Headers: Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet

**Edge cases:**
- Empty data: Return error or empty file with headers
- Invalid format: 400 Bad Request
- Date parsing errors: Return 400
