# Plan 16.02: Offer System

## Objective
Build offer submission form with AI evaluation rules engine and auto accept/reject logic.

## Tasks

1. **Add Offer model to schema**
   - Add `evaluatedBy`, `evaluationResult`, `letter` fields

2. **Create offer-service.ts**
   - `createOffer()`
   - `evaluateOffer()` - rule engine
   - `acceptOffer()` / `rejectOffer()`

3. **Create API route: /api/v1/offers**
   - POST /api/v1/offers - submit offer
   - PATCH /api/v1/offers/[id]/accept
   - PATCH /api/v1/offers/[id]/reject

4. **Create UI: OfferSubmissionForm**
   - Amount input (RM)
   - Move-in date picker
   - Terms acceptance checkbox

5. **Create AI evaluation rules**
   - Below market rate → auto-reject threshold
   - Above asking → auto-accept  
   - Mid-range → flag for manual review
