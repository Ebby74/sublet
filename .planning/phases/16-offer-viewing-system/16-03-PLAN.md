# Plan 16.03: Offer Flow Integration

## Objective
Integrate offer flow: generate offer letter on accept, create tenant, link to lease.

## Tasks

1. **Create offer-letter-service.ts**
   - `generateOfferLetter()` - PDF generation
   - `sendOfferLetter()` - email to prospect

2. **API: /api/v1/offers/[id]/letter**
   - Generate and return PDF

3. **Auto-create tenant on accept**
   - On offer accepted, show "Create Tenant" button
   - Redirect to lease wizard with pre-filled data

4. **Integration with Phase 3 (Lease)**
   - Link accepted offer → lease agreement
   - Track offer conversion rate

5. **Dashboard analytics**
   - Offers by status count
   - Conversion rate chart
