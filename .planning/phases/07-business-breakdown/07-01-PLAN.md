## Task 1.1: Create Business Summary Service

Create `src/services/business-summary-service.ts` with functions:

### getYtdStats(userId: string, year?: number)
Returns YTD financials with YoY comparison.

```typescript
interface YtdStats {
  ytdIncome: number;        // in sen
  ytdExpenses: number;
  ytdNetProfit: number;
  prevYtdIncome: number;
  prevYtdExpenses: number;
  prevYtdNetProfit: number;
  incomeChange: number;     // percentage
  expenseChange: number;
  profitChange: number;
}
```

Logic:
- Query payments where paidAt is between Jan 1 and today
- Sum income (type='income') and expenses (type='expense')
- Repeat for previous year
- Calculate percentage changes

### getPropertyBreakdown(userId: string, groupByType?: boolean)
Returns per-property income/expense/profit breakdown.

```typescript
interface PropertyBreakdown {
  propertyId: string;
  propertyName: string;
  propertyType: string;
  status: string;
  totalIncome: number;
  totalExpenses: number;
  netProfit: number;
  occupancyRate: number;
}
```

Logic:
- Query all properties for user
- For each property, sum payments linked via leases
- Calculate occupancy rate from active leases
- If groupByType, aggregate by property type

### getTenantAnalytics(userId: string, sortBy?: TenantSortBy)
Returns tenant analytics with payment history and punctuality.

```typescript
type TenantSortBy = 'revenue' | 'name' | 'expiry' | 'punctuality';

interface TenantAnalytics {
  tenantId: string;
  tenantName: string;
  email: string;
  phone: string;
  activeLease: {
    propertyName: string;
    monthlyRent: number;
    endDate: Date;
    daysUntilExpiry: number;
  } | null;
  totalPaid: number;
  totalPaidThisYear: number;
  paymentsCount: number;
  onTimePayments: number;
  latePayments: number;
  punctualityScore: number;
}
```

Logic:
- Query all tenants with their leases and payments
- For each tenant, calculate total paid, punctuality score
- Determine active lease and days until expiry
- Sort based on sortBy parameter

### getCashFlowForecast(userId: string, months?: number)
Returns next N months expected income and expenses.

```typescript
interface CashFlowForecast {
  months: {
    month: string;
    expectedIncome: number;
    expectedExpenses: number;
    netCashFlow: number;
  }[];
  summary: {
    totalExpectedIncome: number;
    totalExpectedExpenses: number;
    netForecast: number;
  };
}
```

Logic:
- Expected income: Sum monthlyRentSen for all active leases
- Expected expenses: Average of past 3 months expenses (recurring bills)
- Calculate net cash flow per month
