## Task 1.1: Update Database Schema

**File:** prisma/schema.prisma

Add `incomeSource` field to Payment model:

```prisma
model Payment {
  id              String    @id @default(uuid())
  type            String    // income or expense
  amountSen       Int       // Amount in sen
  description     String?
  referenceNumber String?
  paidAt          DateTime?
  dueDate         DateTime?
  status          String    @default("pending") // pending, paid, overdue, cancelled
  leaseId         String?
  lease           Lease?    @relation(fields: [leaseId], references: [id])
  tenantId        String?
  tenant          Tenant?   @relation(fields: [tenantId], references: [id])
  category        String?   // LHDN expense category
  incomeSource    String?   // NEW: sublet, autoren_sell, autoren_rent, unallocated
  createdAt       DateTime  @default(now())
  updatedAt       DateTime  @updatedAt
  deletedAt       DateTime?

  @@index([incomeSource])
  @@index([type])
  @@index([status])
}
```

Add enum comment for clarity:
```prisma
// incomeSource values:
// - "sublet" - Sublet business unit
// - "autoren_sell" - Property sales commissions
// - "autoren_rent" - Property rental commissions
// - "unallocated" - Not yet tagged (default for existing expenses)
```

## Implementation Notes
- Existing payments will have incomeSource = null (treated as "unallocated")
- Only applies to expenses (type = "expense")
- Income payments will typically be auto-tagged based on related lease/source
- Add index for query performance on incomeSource filter
